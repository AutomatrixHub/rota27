# Rota 27 v0.15 DEV.2 — laboratório Android seguro

Objetivo: testar a v0.15 em um Android real **sem publicar a DEV na `main` e sem substituir a PWA v0.14 instalada**.

## Estratégia

O PC serve a branch `feature/v0.15-multidispositivo` pela rede local, na porta 3000. O Android abre `v015-preview.html` diretamente no Chrome usando o IPv4 do PC.

A produção continua isolada:

- GitHub Pages / `main` permanece v0.14;
- o Service Worker de produção não é alterado;
- a PWA instalada no Android não precisa ser removida;
- o laboratório usa uma origem HTTP de LAN diferente da origem HTTPS de produção, portanto possui armazenamento local separado.

## Iniciar

No PowerShell:

```powershell
cd "C:\Users\marco\OneDrive\Documentos\Rota27\mvp\Rota27-comandas-git"
git pull
.\scripts\start-v015-android-lab.ps1
```

O script:

1. verifica a branch `feature/v0.15-multidispositivo`;
2. detecta o IPv4 LAN do PC;
3. inicia/reutiliza `http-server` em `0.0.0.0:3000`;
4. mostra a URL exata para abrir no Android;
5. abre a DEV.2 localmente no PC para conferência.

Exemplo de URL Android:

```text
http://192.168.1.25:3000/v015-preview.html?dev=2&lab=android
```

O IP real é detectado pelo script; não use o exemplo acima se for diferente.

## No Android

1. PC e Android devem estar na mesma rede Wi-Fi/LAN confiável.
2. Deixe a PWA v0.14 instalada fechada.
3. Abra o Chrome e acesse a URL exibida pelo script.
4. Confirme o badge `v0.15 DEV.2`.
5. Em Cardápio → Sincronização entre aparelhos, configure a Edge Function/token.
6. Dê um nome próprio ao aparelho, por exemplo `ANDROID-LAB`.
7. Use **Adotar base compartilhada**; não use Publicar como base em um aparelho secundário.

## Segurança

- Se o Windows Firewall solicitar permissão para Node/http-server, permita **somente Redes privadas**.
- Não abra a porta 3000 no roteador e não configure port forwarding.
- Encerre o servidor depois do teste fechando a janela PowerShell do `http-server`.
- Não exponha o token do dispositivo em screenshots, chat ou GitHub.

## Importante sobre instalação

Esse laboratório por `http://<IP-LAN>` deve ser usado no navegador. Ele não pretende substituir a instalação PWA de produção. PWAs/Service Workers possuem requisitos de contexto seguro; a publicação final continuará sendo feita via HTTPS no GitHub Pages depois da aprovação da RC.

## Voltar à produção

Para usar o aplicativo normal no Android, feche a aba do laboratório e abra o ícone já instalado da Rota 27. Ele continuará apontando para a v0.14 publicada na `main` até que a v0.15 seja oficialmente promovida.
