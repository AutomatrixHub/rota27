# Rota 27 v0.15 — laboratório público isolado

## Objetivo

Permitir testar a v0.15 DEV.2.1 em Android/iPhone fora da rede local, sem alterar a `main`, sem atualizar o GitHub Pages de produção e sem substituir a PWA v0.14 instalada.

## Correção de arquitetura

A tentativa inicial usava uma Edge Function Supabase (`rota27-lab`) para servir o HTML. Isso não funciona corretamente em Supabase Hosted Edge Functions sem custom domain: respostas `GET` com `Content-Type: text/html` são reescritas para `text/plain`, fazendo o navegador exibir o código-fonte em vez de renderizar o aplicativo.

Por isso o laboratório público passa a usar uma URL de preview/CDN que serve arquivos do GitHub com os Content-Types corretos. O build continua fixado por commit, mantendo o laboratório imutável e separado da produção.

Build fixado:

`59e5f2c4d530e0ff09474130383e9b3de20c4925`

Esse commit corresponde à v0.15 DEV.2.1 validada no Android local.

## URL pública

`https://rawcdn.githack.com/AutomatrixHub/rota27/59e5f2c4d530e0ff09474130383e9b3de20c4925/v015-preview.html?dev=2&lab=public&fix=021`

Como a URL usa um SHA específico, mudanças futuras na branch não alteram este laboratório. Para uma nova DEV, deve-se apontar para um novo commit validado.

## Segurança

- `main`/v0.14 permanece intacta;
- GitHub Pages de produção permanece intacto;
- nenhum segredo é embutido no HTML/JS público;
- a sincronização continua exigindo o `x-rota27-device-token` configurado localmente no aparelho;
- `rota27-sync` e `rota27-whatsapp` não são alteradas pelo laboratório;
- o laboratório não deve ser instalado por cima da PWA v0.14 de produção;
- o provedor de preview pode exibir uma confirmação de segurança na primeira abertura de uma página HTML.

## Uso no Android

1. abrir a URL pública no Chrome, em qualquer rede com internet;
2. confirmar `v0.15 DEV.2.1`;
3. abrir Cardápio > Sincronização entre aparelhos;
4. configurar o mesmo endpoint `rota27-sync` e o Device Token já usado nos outros aparelhos;
5. nomear o aparelho, por exemplo `ANDROID-PUBLIC-LAB`;
6. como já existe base remota, usar `Adotar base compartilhada`;
7. não instalar essa DEV por cima da PWA v0.14 de produção.
