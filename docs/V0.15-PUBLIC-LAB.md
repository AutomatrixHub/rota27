# Rota 27 v0.15 — laboratório público isolado

## Objetivo

Permitir testar a v0.15 DEV.2.1 em Android/iPhone fora da rede local, sem alterar a `main`, sem atualizar o GitHub Pages de produção e sem substituir a PWA v0.14 instalada.

## Arquitetura

O laboratório é servido por uma Edge Function separada, `rota27-lab`, no mesmo projeto Supabase.

A função atua somente como host/proxy estático de um build fixado por commit do repositório GitHub. Ela não contém `ROTA27_DEVICE_TOKEN`, não executa migrations e não altera `rota27-sync` nem `rota27-whatsapp`.

Build fixado:

`59e5f2c4d530e0ff09474130383e9b3de20c4925`

Esse commit corresponde à v0.15 DEV.2.1 validada no Android local.

## Segurança

- `main`/v0.14 permanece intacta;
- GitHub Pages de produção permanece intacto;
- a função permite apenas arquivos estáticos necessários ao app (`v015-preview.html`, `base-v013.html`, `assets/*`, `icons/*`, `manifest.webmanifest`);
- traversal de caminho é bloqueado;
- cache é desabilitado para evitar DEV antiga;
- `sw.js` do laboratório é neutro para não criar cache persistente de desenvolvimento;
- nenhum segredo é embutido no HTML/JS público;
- a sincronização continua exigindo o `x-rota27-device-token` configurado localmente no aparelho.

O script publica somente `rota27-lab` com Verify JWT OFF, necessário porque o navegador precisa buscar arquivos públicos sem Authorization. A função não expõe dados e não contém autenticação operacional; as APIs de sync continuam protegidas separadamente.

Após o deploy, o script faz health check e imprime a URL pública do laboratório.

URL esperada:

`https://owkvwsiblbzlpxjwybrt.supabase.co/functions/v1/rota27-lab/v015-preview.html?dev=2&lab=public&fix=021`

## Uso no Android

1. abrir a URL acima no Chrome, em qualquer rede com internet;
2. confirmar `v0.15 DEV.2.1`;
3. abrir Cardápio > Sincronização entre aparelhos;
4. configurar o mesmo endpoint `rota27-sync` e o Device Token já usado nos outros aparelhos;
5. nomear o aparelho, por exemplo `ANDROID-LAB`;
6. como já existe base remota, usar `Adotar base compartilhada`;
7. não instalar essa DEV por cima da PWA v0.14 de produção.

## Atualizações futuras

O host é deliberadamente fixado por SHA. Isso evita que um push novo mude o laboratório sem controle. Para publicar uma DEV posterior, atualize `PINNED_REV` em `supabase/functions/rota27-lab/index.ts`, valide o commit e republique `rota27-lab`.
